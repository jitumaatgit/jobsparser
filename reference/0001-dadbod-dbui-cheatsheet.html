dadbod / dadbod-ui — cheat sheet

For browsing data/jobs.db in Neovim. Connection: jobsparser (vim.g.dbs).

The path to browse a table

:DBUI → o jobsparser → o Tables (7) → o jobs → o List → :w → read .dbout

Every hop is the same key: o opens or toggles. Opening a node connects/fills but does not run — you run by saving (:w).

Run SQL without the drawer

:DB sqlite:data/jobs.db SELECT count(*) FROM jobs;
:DB sqlite:data/jobs.db            " interactive console (q to leave)

-- full-text match via the FTS index (prewrapped for the jobs table):
SELECT title, company, location, date_posted, job_url
FROM jobs
WHERE rowid IN (SELECT rowid FROM jobs_fts WHERE jobs_fts MATCH '"entry level" NOT CDL')
ORDER BY date_posted DESC;

Paste any of this into a SQL buffer (it connects to the current b:db) or after :DB <url>. :help :DB.

Defaults that surprise people

  • Opening a table helper does not run it — g:db_ui_auto_execute_table_helpers = 0.
  • Saving a SQL buffer does run it — g:db_ui_execute_on_save = 1.
  • SQLite table helpers: List, Columns, Primary Keys, Indexes, Foreign Keys.
  • Default List query: SELECT * from "jobs" LIMIT 200;.
